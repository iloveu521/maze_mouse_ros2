# 左墙跟随 0.5 m/s 验证

2026-11-01（Asia/Shanghai），ROS 2 Humble、Gazebo Classic 11、TurtleBot3 Burger，CMake 3.22.1 与 C++20。本文件只记录左墙控制器，旧泛洪数据保留在 `validation.md`。

## 自动检查

核心雷达/泛洪的 8 项既有 C++ 测试及新增 7 项左墙 C++ 测试均通过，另完成地图几何检查。左墙检查覆盖：

- 直道指令能够达到 0.5 m/s，数据无效立即停车。
- 左侧开口优先于前方和右方，开口必须由不同雷达帧确认。
- 前方受阻时选择右转或死胡同回退。
- 过近障碍、无效扇区和到达目标时停车。
- 路口到位及转角、线速度、角速度需要连续稳定确认。
- 动作超时停止，避免持续原地寻迹或卡住。
- 读取实际 world 的碰撞几何，以 360 点、5 Hz 射线雷达和 20 Hz 控制进行完整运动学跑图；始终检查半径 0.13 m 圆形包络与墙体的距离。

运动学检查结果：约 203.55 s 完成，中心轨迹到墙面的最小距离约 0.3977 m，最大线速度指令 0.5 m/s。此数值来自简化运动学模型，未当作 Gazebo 动力学结果。原始输出见 [几何检查日志](left_wall_geometry.log)。

## 调试与比较范围

早期局部圆弧方案曾在 Gazebo 中出现末端绕圈与转角过冲，未作为最终交付方案。相关尝试记录分别见 [首次圆弧日志](left_wall_first_corner_attempt.log)、[后续圆弧日志](left_wall_arc_attempt.log)及[停车终态](left_wall_arc_attempt_result.yaml)。最终版本改为路口减速到位后闭环转向，不在每个直行格点停车。

旧泛洪实测约 503.7 s、51.34 m，速度为 0.20 m/s，且每格停车观测；本次左墙测试的速度、路线、停车策略和到达阈值均有所不同，耗时差异不能单独归因于算法计算复杂度。0.5 m/s 是 Gazebo 仿真指令配置，不作为 Burger 实车性能结论。
